# Реализация требований и ограничения

Это сводка реализации по доступному тексту ТЗ, а не заявление о полном соответствии или акт
приёмки.

## Отклонения и ограничения

| Область          | Фактическое состояние                                                                                                                                                                                       |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Языки разработки | В ТЗ перечислены Python, C#, C++ и Java. Клиент и сервер реализованы на TypeScript/Node.js, desktop-оболочка — на JavaScript/Electron. Требование к языкам не выполнено; это осознанное отклонение проекта. |
| Карта без сети   | Подложка Esri World Imagery требует интернет-доступа. При сбое показываются радарная геометрия и схема РЛС, но офлайн-картографической подложки нет.                                                        |
| Настройка зон    | В интерфейсе можно скрывать и показывать зоны. Их геометрия задана в `client/src/features/simulation/lib/config.ts`; редактора полигонов нет.                                                               |
| Детали поведения | Формат части элементов интерфейса и сценарии из упомянутой в ТЗ ЧТЗ нельзя подтвердить по предоставленному описанию.                                                                                        |

## Реализованные области

| Область             | Реализация                                                                                                                                                                                                                                                                                                                                                           |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Desktop для Windows | Electron-оболочка открывает renderer по `app://rls.local`. API слушает loopback на динамическом порту; порт передаётся основному процессу по IPC. Команды упаковки: `npm run desktop:package` (NSIS) и `npm run desktop:package:zip` (ZIP), Windows x64.                                                                                                             |
| Авторизация и роли  | Роли администратора и оператора проверяются на сервере. Начальный или сброшенный пароль требуется сменить до доступа к основным API; смена пароля отзывает прежние JWT.                                                                                                                                                                                              |
| Хранение данных     | Пользователи, история тренировок и архив событий сохраняются в локальном `rls-data.json`; Electron размещает файл в каталоге приложения `userData`. История ограничена 100 тренировками и 30 событиями на пользователя.                                                                                                                                              |
| Тренировка          | Настройки сеанса, карта и радарные зоны, цели БВС и птицы, пауза и возобновление, отметка цели двойным щелчком, результаты и статистика в профиле. Геометрия зон и параметры симуляции находятся в исходном коде.                                                                                                                                                    |
| Архив тревог        | События сохраняются с данными цели, снимком экрана и миниатюрой. Снимок включает отметки видимых целей, когда браузерная среда и внешние ресурсы позволяют их захватить.                                                                                                                                                                                             |
| Очередь результатов | Клиент сохраняет неизменяемый снимок активной тренировки в localStorage примерно каждые 5 секунд и после отметки цели. При завершении или закрытии страницы запись становится готовой к отправке; очередь восстанавливается после запуска и повторяет отправку при подключении и примерно каждые 10 секунд. `sessionId` обеспечивает идемпотентный приём на сервере. |

## Проверки проекта

Команды, доступные в репозитории:

```bash
npm test                 # Vitest: клиентская логика и API
npm run test:desktop     # smoke-тесты Electron-оболочки
npm run test:e2e         # Playwright E2E
npm run build            # клиент и обычная серверная сборка
npm run desktop:package  # Windows x64 NSIS
npm run desktop:package:zip
npm run lint
npm run typecheck
```

Наличие команды само по себе не означает, что соответствующий сценарий проверен на каждой
целевой системе. Результаты конкретного прогона следует фиксировать отдельно.
