# Тренажёр оператора РЛС «Центр 2401»

Десктопный тренажёр для тренировки навыка обнаружения и определения объектов типа «БВС»
по данным радиолокационной станции. Проект разработан для хакатона «Архипелаг 2025».

## Что умеет приложение

- **Авторизация** с двумя ролями: «Администратор» (управление пользователями) и «Оператор».
  Сохранённая сессия проверяется на сервере при каждом запуске приложения.
- **Режим «Тренировка»**: окно настроек сеанса → карта с радарными кольцами, зонами
  обнаружения и игнорирования, генерируемыми объектами (БВС и птицы).
- **Определение объекта как БВС** двойным щелчком левой кнопкой мыши по его точке.
- **Центр уведомлений** с визуальными и звуковыми тревогами о входе цели в зону обнаружения.
- **Архив событий**: снимок экрана при каждой тревоге (тревога во время тренировки,
  вкладка «Архив событий» центра уведомлений).
- **Окно результатов** сеанса: время, количество отмеченных целей, ошибки, среднее время
  определения. Результаты сохраняются на сервере и отражаются в разделе «Профиль».
- **Профиль**: карточка пользователя, история тренировок, статистика (график времени реакции),
  смена пароля, выход из системы.
- **Настройки**: графика карты, звук (вкл/выкл и громкость), управление пользователями
  и правами доступа для роли «Администратор».

## Быстрый старт

```bash
npm install
npm run dev
```

`npm run dev` поднимает оба сервера одновременно:

- клиент (Vite) — <http://localhost:5173>
- API (Express) — <http://localhost:3001>

Откройте <http://localhost:5173> и войдите под `admin` / `admin`.

## Сценарии запуска

| Сценарий | Команда | Что происходит |
| --- | --- | --- |
| Разработка | `npm run dev` | Vite с HMR + API с автоперезапуском (`tsx watch`) |
| Сборка приложения | `npm run build` | `client/dist` (статика) и `server/dist` (ESM-сервер) |
| Запуск собранного приложения без Electron | `npm run build && npm run start -w server` | Сервер раздаёт `client/dist` и API на <http://localhost:3001> |
| Десктопное приложение (Electron) | `npm run desktop` | Сборка + окно Electron 1440×900, внутри поднимается API-сервер |
| Тесты | `npm run test` | Vitest: логика зон, обнаружения и определение целей |
| Проверки | `npm run lint`, `npm run typecheck` | ESLint (flat config) и `tsc --noEmit` для обоих воркспейсов |

Порт API задаётся переменной окружения `PORT` (по умолчанию `3001`). Секрет JWT берётся из
`JWT_SECRET`; если переменная не задана, сервер генерирует случайный секрет на время работы.

Важно: `JWT_SECRET` фиксирует только подпись токена. Сессии между перезапусками сохраняются
лишь вместе с постоянным хранилищем пользователей — при in-memory хранилище идентификаторы
пользователей создаются заново, поэтому вход требуется при каждом запуске приложения
(это соответствует п.3.3.3 ТЗ: «Меню авторизации появляется при включении ПО»).

## Учётные записи

| Логин | Пароль | Роль | Возможности |
| --- | --- | --- | --- |
| `admin` | `admin` | Администратор | Тренировка, профиль, настройки, управление пользователями |
| `operator` | `operator` | Оператор | Тренировка, профиль (без раздела управления пользователями) |

Хранилище данных — in-memory: пользователи, сеансы и архив событий существуют в рамках
запущенного процесса сервера и создаются заново при старте.

## Команды

```bash
npm run dev         # клиент + сервер в режиме разработки
npm run build       # production-сборка обоих воркспейсов
npm run desktop     # сборка + запуск Electron-оболочки
npm run test        # unit-тесты (Vitest)
npm run lint        # ESLint
npm run typecheck   # проверка типов TypeScript
```

## Структура репозитория

```
rls-simulator/
├── client/                  # SPA: Vite + React + TypeScript (FSD-подобная структура)
│   └── src/
│       ├── app/             # провайдеры, роутер, layout, ProtectedRoute, ErrorBoundary
│       ├── pages/           # Login, MainMenu, Simulation, Profile, Settings
│       ├── widgets/         # Map, MapControls, TopBar, SideMenu, NotificationsPanel, …
│       ├── features/        # simulation (движок), auth, events, sessions, settings, users
│       ├── entities/        # типы и словари предметной области: user, target, session, event
│       └── shared/          # api, lib (geo, format, units, hotkeys), ui, styles
├── server/                  # Express + JWT + zod, in-memory хранилище
│   └── src/
│       ├── modules/         # auth, sessions, users, events
│       └── shared/          # db, mappers, middleware (authGuard, requireAdmin, errorHandler)
├── desktop/                 # Electron-оболочка (main.cjs)
└── vitest.config.ts         # конфигурация тестов
```
