# Тренажёр оператора РЛС "Центр 2401"

Десктопный тренажёр для практики обнаружения и определения целей типа "БВС".
Клиент написан на React и TypeScript, API - на Node.js, оболочка - на Electron.

## Возможности

- Тренировки с генерируемыми целями, радарными кольцами, зонами и настройками сеанса.
- Отметка целей двойным щелчком, тревоги, звуковые уведомления и архив событий со снимками.
- Профиль с историей тренировок, статистикой и сменой пароля.
- Роли администратора и оператора; управление пользователями доступно администратору.
- Результаты тренировок автоматически сохраняются в локальную очередь и повторно отправляются
  при восстановлении соединения. Очередь привязана к пользователю и идентификатору сеанса.

## Требования

| Компонент | Требование          |
| --------- | ------------------- |
| Node.js   | 22.x, не ниже 22.18 |
| npm       | 10.x или новее      |
| Поставка  | Windows 10/11, x64  |

## Быстрый старт

```bash
npm ci
npm run dev
```

Откройте <http://localhost:5173>. Начальные учётные записи - `admin` / `admin` и
`operator` / `operator`; при первом входе приложение требует сменить пароль.

Для разработки Vite доступен на порту 5173, API - на `127.0.0.1:3001`. В Electron renderer
работает по постоянному адресу `app://rls.local`. Оболочка выбирает динамический loopback-порт
для API и передаёт его основному процессу через IPC; запросы `/api` проксируются через него.

## Локальные данные

Пользователи, пароли в виде bcrypt-хешей, история тренировок, архив событий и секрет подписи
JWT хранятся в `rls-data.json` в каталоге `RLS_DATA_DIR`. Если переменная не задана, используется
`~/.rls-simulator`; Electron задаёт каталог данных приложения внутри `userData`. Секрет JWT
генерируется и сохраняется при первом запуске. При заданном `JWT_SECRET` сервер использует его;
значение должно содержать не менее 32 байт UTF-8 и оставаться постоянным между запусками.

Seed-ID и секрет сохраняются, поэтому токены и данные переживают перезапуск. История хранит до
100 тренировок и 30 событий на пользователя. Незавершённые результаты сначала синхронно
фиксируются в локальной очереди клиента примерно каждые 5 секунд и после отметки цели; при
завершении тренировки или закрытии страницы запись помечается готовой к отправке. Сервер
обрабатывает повторную отправку одного `sessionId` идемпотентно.

Спутниковые тайлы Esri загружаются из сети. При недоступности сервиса остаются радарная
геометрия и схематичное отображение; офлайн-картографической подложки в приложении нет.

## Структура

```text
client/       React SPA, карта и логика симуляции
server/       Express API и локальное JSON-хранилище
desktop/      Electron-оболочка и проверки её запуска
scripts/      Сборка desktop-сервера
```

## Лицензии зависимостей

Сборка генерирует `THIRD_PARTY_NOTICES.txt` из установленных production-зависимостей и включает
его в поставку. Electron также содержит собственные файлы лицензий. Лицензия исходного проекта
должна быть выбрана автором отдельно.
